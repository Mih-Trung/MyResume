# Nguyễn Minh Trung — CV & Research Portfolio

Static, one-page academic portfolio based on the [AppliedMathUC Minimal Academic Website Template](https://github.com/AppliedMathUC/Website).

## Run locally

From this folder, run:

```powershell
python -m http.server 4173 --bind 127.0.0.1
```

Then open `http://127.0.0.1:4173/`.

## Content

- `index.html`: CV, applied projects, education, activities, skills, and contact information.
- `publications.json`: research-portfolio entries rendered by `scripts.js`.
- `styles.css`: the template styling plus portfolio-specific responsive rules.

Research entries are deliberately labelled unpublished or in progress where applicable.
